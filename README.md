# Horra — Full Landing Page

This package is a static, production-oriented Horra landing site built from the supplied `horra-app.html` product reference.

## Important
- No AI-generated photos or stock photos are used.
- The hero is a clean banner composition using the actual second Horra app screen from the supplied screenshot (`assets/horra-hero-screen.jpg`) alongside the primary product message.
- The remaining product showcase is built as HTML/CSS UI so it remains editable and lightweight.
- No company certificate is included.
- The site does not claim a Meta/WhatsApp partnership.
- The WhatsApp wording is intentionally limited to the actual product flow: Horra helps draft; the user reviews and sends through WhatsApp.

## Files
- `index.html` — full landing page
- `about.html` — About Horra
- `privacy.html` — Privacy Policy
- `terms.html` — Terms & Conditions
- `styles.css` — main design system
- `legal.css` — legal-page styles
- `script.js` — mobile navigation and smooth scrolling
- `robots.txt`
- `sitemap.xml`

## Run locally
Open `index.html` directly in a browser, or use a local server such as:
`python -m http.server 8000`

Then visit:
`http://localhost:8000`

## Before production
1. Replace `https://horraapp.com/` if the final domain differs.
2. Verify legal entity, contact emails and legal text with your final business/legal information.
3. Connect the Get Started CTA to the actual Horra app.
4. Add your official favicon/app icon if available.
5. If you have approved real product screenshots, they can replace the CSS product frames without changing the overall layout.


## Logo
The header and footer use the Horra wordmark taken from the supplied first-screen logo reference, with transparent background variants for light and dark surfaces.
